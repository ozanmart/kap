# Security policy

Please do not open a public issue for a suspected vulnerability that could
expose credentials, private data, or a remotely exploitable behavior. Use a
private GitHub Security Advisory for this repository (or contact the repository
maintainer privately) with reproduction steps, affected versions, and impact.

The project does not require credentials for its public KAP read-only endpoints.
Never commit API keys, cookies, session headers, personal data, or local cache
databases. Remove those values from logs and fixtures before sharing a report.
